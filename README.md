# Burp Suite Web Application Security Testing

## Overview
This project demonstrates practical web application security testing using Burp Suite Community Edition in a controlled DVWA environment. The focus is on understanding HTTP traffic flow, request interception, authentication analysis, and vulnerability testing techniques.

---

## Objectives
- Analyse HTTP requests and responses
- Intercept and modify web traffic using Burp Proxy
- Understand authentication and session handling
- Use Burp tools (Proxy, Repeater, Decoder, HTTP History)
- Explore how user input affects server behaviour

---

## Tools Used
- Burp Suite Community Edition
- Kali Linux
- DVWA (Damn Vulnerable Web Application)
- Chromium Browser (Burp integrated)
- Base64 Decoder

---

## Key Activities

### 1. HTTP Traffic Interception
- Captured and analysed HTTP requests using Burp Proxy
- Controlled traffic flow using Intercept, Forward, and Drop

### 2. HTTP History Analysis
- Reviewed captured requests and responses
- Identified methods, headers, and status codes

### 3. Authentication Testing
- Captured login credentials during POST request submission
- Analysed session data and cookies

### 4. Repeater Testing
- Modified HTTP requests manually
- Observed server response changes based on input manipulation

### 5. Decoder Tool Usage
- Decoded Base64 encoded credentials
- Retrieved plaintext authentication data

---

## Skills Demonstrated
- Web Traffic Analysis
- HTTP Request/Response Handling
- Authentication Mechanism Testing
- Session Handling Concepts
- Parameter Manipulation
- Security Tool Proficiency (Burp Suite)
- Data Encoding/Decoding (Base64)

---

## Key Learning Outcome
This exercise demonstrated how web applications transmit sensitive data and how interception tools can be used to analyse and manipulate HTTP traffic for security testing purposes.
